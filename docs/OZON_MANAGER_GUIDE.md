# Ozon в Sellico — инструкция для менеджеров

Всё находится в CRM: **sellico.ru/crm → Реклама и цены**. Сверху переключатель **Wildberries | Ozon** — выбираем Ozon. Правее — выбор магазина (кабинета). В списке видны только магазины, у которых в интеграции Sellico добавлены ключи Performance API.

## Разделы Ozon (вкладки сверху)

| Вкладка | Что там |
|---|---|
| **Кампании** | Рекламные кампании: «Оплата за клик» и «Оплата за заказ» |
| **Стратегии** | Автоматические стратегии ставок и цен |
| **Цены** | Репрайсер: цены, пол цены, конкуренты, **тепловая карта спроса** |
| **Календарь цен** | Запланированные изменения цен по датам |
| **AI-центр** | ИИ-автопилот: решения, прогоны, включение |

---

## 1. Кампании

**Список**: тип кампании, статус, бюджет, показы/клики/расход/заказы/ДРР за 7 дней. Иконка в строке — быстрая пауза/запуск.

**Деталка кампании** (клик по строке):
- Кнопки **«Приостановить/Запустить»** и **«Бюджет»** (меняется тот тип бюджета, который задан у кампании — дневной или недельный, тип менять нельзя, это ограничение Ozon).
- **Товары и ставки**: клик по ставке → ввод новой цены клика в ₽ → кнопка «Сохранить ставки». Кнопка **«Показать конкурентные»** подтягивает ставки конкурентов из Ozon — ориентир, сколько платят соперники за клик по этим товарам.
- **История ставок** внизу: кто и когда менял ставку (вручную / стратегия / ИИ), старая → новая, статус.

**Вкладка «Оплата за заказ» (CPO)**: продвижение с оплатой только за выкупленный заказ — безрисковый инструмент, ДРР не «сливается». Включаем товары галочками, ставим ставки, «Сохранить». Рекомендация: держать включённым на весь ликвидный ассортимент с минимальными ставками.

## 2. Стратегии ставок

**«Целевой ДРР»** — автоматика держит долю рекламных расходов у цели. Создаётся на вкладке Стратегии: задаёте целевой ДРР (например 15%), мин/макс ставку, и **уровень**:
- **Тень** — стратегия только записывает решения в историю, ничего не меняет. С неё начинаем всегда.
- **С подтверждением** — предлагает изменения, менеджер жмёт «Применить».
- **Автопилот** — применяет сама в заданных рамках.

Защита встроена: не больше N изменений в день, кулдаун между изменениями, ставки только в заданном диапазоне.

## 3. ИИ-автопилот (AI-центр)

Искусственный интеллект раз в 4 часа анализирует все кампании кабинета (статистику, ставки, конкурентов, маржу товаров) и формирует решения: снизить/поднять ставку, приостановить кампанию, включить CPO и т.д. **Каждое решение проходит те же защитные лимиты — ИИ физически не может «слить бюджет».**

- Включение: AI-центр → «Включить ИИ-автопилот» → целевой ДРР + уровень (те же Тень/Copilot/Автопилот). **Начинаем с Тени на 3–7 дней**, читаем ленту решений — у каждого написано обоснование по-русски и ожидаемый эффект.
- В режиме Copilot у решений появляются кнопки **«Применить» / «Отклонить»**.
- «Запустить анализ сейчас» — внеплановый прогон. История прогонов внизу (со сводкой от ИИ).
- Если ИИ пишет «действий ноль — нет данных» — это нормально: в кабинете нет активного расхода, оптимизировать нечего.

## 4. Репрайсер (вкладка Цены)

Таблица товаров: цена, **«Пол цены»** (себестоимость + комиссии Ozon + целевая маржа — ниже неё продавать в убыток; цена подсвечена красным, если ниже пола), **«Конкуренты»** (мин. цена конкурентов из индекса цен Ozon), комиссии FBO/FBS, индекс цен.

- **Ручное изменение**: клик по цене → ввод → «Сохранить цены».
- **Тепловая карта спроса** — аккордеон на этой же вкладке (Цены → «Тепловая карта спроса»). Сетка 7 дней × 24 часа, построена из времени реальных заказов за 28 дней (МСК). Тёмные клетки — часы пикового спроса. Можно по всему магазину или по конкретному товару (поиск).
- **Пауза репрайсера** — кнопка в строке состояния сверху (стратегии останавливаются, ручные правки работают).
- **История изменений** (вкладка) — каждое изменение цены с источником и кнопкой **«Откатить»**.

**Стратегии цен** (карточки на вкладке Цены, все стартуют в режиме «Черновик (dry-run)» — неделю пишут, что бы сделали, ничего не меняя):
1. **Пол маржи** — никогда не продавать ниже пола; поднимает цену до пола, если упала.
2. **Слежение за конкурентами** — держит цену чуть ниже минимальной у конкурентов (−2% по умолчанию), но не ниже пола.
3. **Разгрузка склада** — залежавшийся товар постепенно дешевеет, ходовой при низком остатке дорожает.
4. **Реклама → цена** — если ДРР по товару выше цели, снижает цену для роста конверсии.
5. **Цена по спросу** — дороже в часы пикового спроса, дешевле в «мёртвые» часы (по тепловой карте).

Переводить из «Черновика» в боевой режим — только после просмотра черновиков в Истории изменений.

## 5. Календарь цен

Месячная сетка. **Клик по дате → диалог**: выбираете товар (поиск), новую цену, опционально дату окончания и цену возврата — в конце периода цена вернётся сама (удобно для акций выходного дня). Записи видны цветными плитками: синие — запланированы, зелёные — применены, красные — ошибка. Клик по записи — детали и отмена.

## Подключение нового магазина Ozon

1. Селлер в ЛК Ozon: Настройки → API-ключи → создать ключ **Seller API** (Client-Id + Api-Key) и на вкладке **Performance API** — сервисный аккаунт (client_id + client_secret).
2. Все 4 значения вносятся в интеграцию магазина в Sellico.
3. В течение часа кабинет появится в Ozon-разделе с кампаниями, ценами и статистикой. Без performance-ключей магазин в рекламном разделе не показывается.

## Золотые правила

- Всё новое включаем в **Тени / Черновике**, боевой режим — после просмотра решений.
- ДРР = расход на рекламу ÷ выручка × 100%. Цель по умолчанию 15%.
- «Оплата за заказ» — безопасный инструмент, «Оплата за клик» — требует контроля ставок.
- Любое изменение (ставка, цена) можно найти в истории и откатить.
- Данные Ozon приходят с задержкой до суток — не паникуем из-за «нулей» за сегодня.
